Lead story: Russia strikes Kyiv's bridges and missiles land in Poland — nine killed, NATO acts, Putin rejects a ceasefire. Also in the picture: the International Court of Justice rules Myanmar committed genocide against the Rohingya; Trump, Putin and Xi meet in Beijing; and tech stocks tumble.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` (a 1024×1024 PNG, 786,604 bytes) to `$MAKEFUN_OUTPUT_DIR/entry.png`. Node 22, standard library only, no network access.
